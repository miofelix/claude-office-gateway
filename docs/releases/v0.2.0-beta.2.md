# Claude Office Gateway 0.2.0-beta.2

新增类似 CC Switch 的「轻量模式」：仅保留状态栏／托盘与本地网关运行。

- 在状态栏／托盘菜单勾选「轻量模式」，或在唯一的「高级设置」点击进入。
- 真正释放主窗口与 WebView，Office 网关继续服务；macOS 隐藏 Dock 图标，Windows 释放任务栏窗口。
- 从托盘打开、取消勾选或再次启动应用，会按需重建窗口并恢复连接状态、外观与语言偏好。
- 有未保存的配置时先提示，取消后继续编辑；进行中的配置、证书和更新操作不会被窗口销毁打断。
- 覆盖销毁期间唤起和重复打开；窗口恢复后不重复已完成的启动更新检查。

轻量模式仅作用于当前运行会话，完全退出应用后下次正常启动会显示主窗口。普通关闭仍隐藏窗口；退出应用才停止网关。

## 下载与升级

macOS 提供 Apple Silicon / Intel DMG；Windows x64 提供 EXE / MSI。beta.1 用户可通过标题旁版本号检查更新并手动安装，更新包强制验证签名。

macOS 已进行本机轻量运行、HTTPS 请求、窗口重建和未保存修改保护验证。Windows 自动检查及安装器由原生 Actions 构建，实际 Windows 桌面与 Office 验收待用户测试。

延续 beta.1 的发行签名状态：macOS 为 ad-hoc 签名、尚未公证，Windows 无 Authenticode 签名；应用内更新独立强制验证 Minisign。
