# Claude Office Gateway 0.2.0-beta.4

新增多个 Provider profile 的保存与切换能力。

- 可保存多个命名的 Provider profile，每个 profile 独立保存 API 地址、协议、模型、Office 别名和供应商密钥。
- 在「已保存的供应商」中切换 profile；网关运行时禁止切换，避免请求发送到错误的供应商。
- 未保存修改时切换会被阻止，可先保存或放弃修改。
- 旧版单 Provider `settings.json` 自动迁移为 `default` profile，原有密钥继续从旧钥匙串条目读取。
- 新 profile 的密钥按 profile 分开保存到 macOS Keychain 或 Windows Credential Manager。
- 新增多 profile 配置、凭据隔离、迁移和切换回归测试。

## 下载与升级

macOS 提供 Apple Silicon DMG 和签名更新归档；Windows x64 提供 EXE / MSI。macOS Intel 从 beta.3 起不再构建或发布。

Apple Silicon 和 Windows 用户可点击标题旁版本号检查更新并手动安装。更新包继续强制验证 Minisign 签名。

延续已有发行签名状态：macOS 为 ad-hoc 签名，尚未公证；Windows 安装器尚无 Authenticode 签名。
