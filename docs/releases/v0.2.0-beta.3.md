# Claude Office Gateway 0.2.0-beta.3

修复窄窗口布局和重复滚动条，并停止构建 macOS Intel 版本。

- 修复窄窗口右侧同时出现页面滚动条和内容滚动条：复制反馈的隐藏状态文字现在被约束在内容滚动区域内，标题栏保持固定，页面底部仍可正常到达。
- 修复更新说明较长时更新弹窗出现嵌套滚动条；弹窗统一滚动，所有操作仍可滚动到达。
- 修复较长的错误信息或 URL 撑出通知和更新弹窗的问题。
- 修复高缩放、极窄视口下 macOS WebKit 展开高级设置时表单溢出的问题；窄视口中的高级设置使用单列。
- 新增真实 WKWebView 布局回归检查，纳入 macOS CI 和发布检查；覆盖中英文、亮暗外观、窗口尺寸、展开设置、复制反馈、长错误及各类确认／更新弹窗。

## 下载与升级

从本版起，macOS 仅提供 Apple Silicon DMG 和签名更新归档；Windows x64 继续提供 EXE / MSI。后续不再构建或发布 macOS Intel 版本；历史版本下载仍保留。

Apple Silicon 和 Windows 用户可点击标题旁版本号检查更新并手动安装。更新包继续强制验证 Minisign 签名。

延续已有发行签名状态：macOS 为 ad-hoc 签名，尚未公证；Windows 安装器尚无 Authenticode 签名。
