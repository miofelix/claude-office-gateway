# Claude Office Gateway 0.2.0-beta.1

首个 macOS / Windows 公测版，将 Claude 的 PowerPoint、Excel、Word 加载项连接到自己的模型供应商。

- 单页引导界面：证书、供应商设置和 Office 连接步骤集中展示。
- 支持 Anthropic Messages、OpenAI Chat Completions、OpenAI Responses。
- 亮色、暗色、跟随系统；中英文切换；系统托盘快捷操作。
- 显示版本号，启动检查更新，手动下载并验证签名后安装和重启。
- 密钥使用 macOS 钥匙串 / Windows 凭据管理器保存。
- 修复 macOS Office 使用 HTTP/2 时因主机校验被拒绝而出现 Load failed 的问题。

## 下载

- Apple Silicon Mac：`macos-aarch64.dmg`
- Intel Mac：`macos-x86_64.dmg`
- Windows 10/11 x64：`windows-x86_64-setup.exe`（推荐），或 `.msi`
- `.app.tar.gz` 与 `.sig` 用于应用内更新；`latest.json` 为该版本更新清单，`SHA256SUMS` 提供文件校验值。

## 使用

安装后先信任应用生成的 localhost 证书，再填写供应商地址、密钥及模型 ID，并点击连接。在 Office 加载项选择 Gateway、Anthropic 格式和 x-api-key 认证，然后复制应用提供的地址、令牌与模型 ID。Office 模型 ID 必须以 `claude` 开头，例如 `claude-office-custom`；它是映射到真实供应商模型的网关别名。

## 测试版说明

macOS 安装包采用 ad-hoc 签名，尚无 Apple Developer ID 签名或公证；首次从互联网安装可能被 Gatekeeper 拦截。请确认下载来源后，按 macOS「系统设置 → 隐私与安全性」的系统提示打开。

Windows 安装器尚无 Authenticode 代码签名，系统可能提示未知发布者。应用更新另有强制 Minisign 签名验证，与操作系统代码签名独立。

Windows 原生构建和自动化检查由 GitHub Actions 执行；Windows 上的安装、Office 交互及更新替换仍需实际设备验证。macOS 最低版本 13，Windows 需要 WebView2。
